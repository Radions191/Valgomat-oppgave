# Valgomat for Stortingsvalget 2025

## Om prosjektet

Dette prosjektet er en interaktiv valgomat som hjelper brukere å se hvor mye deres meninger samsvarer med Fremskrittspartiet (FrP) i Stortingsvalget 2025. 
Brukeren svarer på spørsmål ved å velge fra "Helt uenig" til "Helt enig", og resultatet vises som en prosentandel som viser hvor godt brukerens holdninger matcher FrP.

## Funksjoner

- Brukeren ser ett spørsmål av gangen.
- Mulighet til å velge ett av fem svaralternativer: "Helt uenig", "Litt uenig", "Nøytral", "Litt enig", "Helt enig".
- Knapper "Tilbake" og "Neste" for navigering mellom spørsmålene.
- Viser resultatet etter alle spørsmålene som en prosentandel.
- Mulighet til å starte testen på nytt.
- Responsivt design: radioknapper vises horisontalt, tekst under knappene, knappene er sentrert.

## Bruk

1. Åpne `index.html` i nettleseren.
2. Velg svar på alle spørsmålene.
3. Klikk på "Neste" for å gå til neste spørsmål.
4. Etter det siste spørsmålet vises resultatet som en prosentandel.
5. Du kan klikke på "Start på nytt" for å ta testen på nytt.
